# Tribute Page – Dr. A.P.J. Abdul Kalam

A simple tribute page dedicated to Dr. A.P.J. Abdul Kalam, the Missile Man of India and the 11th President of India.

## Project Overview

This project is built using basic HTML and is designed to showcase the life, achievements, and inspirational journey of Dr. A.P.J. Abdul Kalam.

## Features

- Tribute page dedicated to Dr. A.P.J. Abdul Kalam
- Biography and introduction
- Career highlights
- Important timeline of events
- Inspirational quote
- External Wikipedia link
- Image of Dr. Kalam

## Technologies Used

- HTML5
